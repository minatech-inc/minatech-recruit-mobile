## 1. 業界需要（Demand）

### 1.1 求人数トレンド（店舗数の推移から推計）
キャリアショップ総店舗数は縮小局面（求人総数の縮小要因）。ただし既存店舗の人手不足は慢性化。

| 指標 | 数値 |
|---|---|
| キャリアショップ総数（2025年3月） | 6,999店 |
| ピーク比（2022年2月） | ▲1,027店（▲13%） |
| 直近半年（2024年9月→2025年3月） | ▲143店 |
| ワイモバイル | 2019年 900店超 → 2025年3月 380店 |
| au | ▲105店/年（▲5%） |
| ドコモ | 方針転換で減少ペース抑制 |
| 楽天モバイル | 唯一の増加（+10店/半年）+リモート契約ショップ拡大 |
| 代理店M&A・破綻・事業譲渡 | 半年で93カ所 |

**出典**: [MCA 2025春プレス](https://www.mca.co.jp/info/careershop-2025-spring-press/) / [BUSINESS NETWORK](https://businessnetwork.jp/article/27629/) / [ITmedia Mobile](https://www.itmedia.co.jp/mobile/articles/2505/21/news155.html)

### 1.2 有効求人倍率・人手不足
- 販売・サービス職全体は2026年下半期も「緩やかに求人増」、人手不足を背景に「定着・育成」目的の採用継続
- 携帯販売員特化の倍率は公表統計なし
- **出典**: [doda 2026下半期](https://doda.jp/guide/market/009.html)

### 1.3 キャリア別需要差

| キャリア | 需要傾向 | 採用示唆 |
|---|---|---|
| au | 統廃合最激 | 人員整理・再配置ニーズ |
| SoftBank | ダブルブランド統合型店舗拡大 | Y!mobile対応スタッフ需要 |
| docomo | 比較的安定 | 継続的採用ニーズ |
| **楽天モバイル** | **店舗数増・無人店舗拡大** | **新規採用需要 最大** |

### 1.4 直営店 vs 販売代理店
- 一次代理店〜五次代理店の階層。**二次代理店以下は手数料薄** → 労働生産性への圧力強い
- キャリアからの手数料減で、代理店は「端末以外の収益源」（金融、フィルム貼付、修理）を模索

### 1.5 地域別需要
- **北海道**: 有効求人倍率 0.9倍（全国平均以下）だが「人がいない」状態。札幌に正社員集中、地方は派遣中心
- **静岡**: 大手派遣会社経由中心。単独統計なし
- **首都圏**: 店舗集約進むも、1店舗あたり人員需要は減っていない

### 1.6 採用単価（業界平均）
- 販売・フード系: 前年比▲12.2万円（改善傾向）
- 営業未経験者: 平均46万円
- 中途採用全体: 80〜110万円

## 2. 従事者属性（Supply-side demographics）

### 2.1 年齢分布
- **公的統計データ未確認**（総務省 就業構造基本調査で「販売従事者」全体は取れるが携帯販売単独の細分なし）
- 業界体感値: **20〜30代中心**、家電量販店販売職の平均年齢32歳

### 2.2 性別分布
- 携帯販売特化データ未確認
- 「販売従事者」全体は女性比率高い。キャリアショップは近年男女フラット化（ドコモ・Y!mobileが女性強化）

### 2.3 学歴・前職
- 学歴不問・資格不要が主流
- 前職の典型: アパレル・飲食・ホテル等の**接客・販売業からの転職**が多いとされる（公的統計なし）

### 2.4 平均勤続・離職率
- **業界二次情報として「入社1年以内に約50%離職」**（信頼性は限定的）
- 公的離職率統計は業界単独では未公表
- 主因: ノルマ／業務複雑さ／長時間労働／クレーム対応

### 2.5 給与レンジ（求人ボックス給料ナビ 2026年7月）

| 区分 | 数値 |
|---|---|
| 正社員 平均年収 | 384〜427万円（中央414万円） |
| 正社員 給与幅 | 328〜805万円 |
| 派遣 平均時給 | 1,400〜1,461円 |
| アルバイト 平均時給 | 1,499円 |
| 業務委託 年収 | 300万〜700万円+（トップ層） |
| 地域差 | 最高428万円（長野）〜最低362万円（沖縄）＝67万円差 |

**MinaTechの日給15,000〜20,000円 → 月22日で月給33〜44万・年収400〜500万** = **業界平均をやや上回るポジション**、業務委託上位層に匹敵

### 2.6 契約形態内訳（業界横断・厚労省調査）
- 正社員: 66.7% / 契約社員: 2.3% / 派遣: 2.0%
- 業務委託は数値未計上（近年拡大）
- 携帯販売業界は派遣・業務委託比率が全職種平均より高いと推察

## 3. 心理・行動傾向（Psychographics & behaviors）

### 3.1 応募動機（TOP5・複数記事から集約）
1. **入りやすさ**: 未経験OK・資格不要・研修充実
2. **給与**: インセンティブ次第で高収入可能性
3. **業界知識**: 最新スマホ・IT・通信に触れられる
4. **スキル汎用性**: 接客・営業・プレゼン力
5. **キャリアパス**: 店長・エリアマネージャー・IT関連職への展開

### 3.2 辞める理由TOP
1. **ノルマのプレッシャー**（不要オプション勧誘の罪悪感）
2. **業務複雑さ**（料金・契約説明のミス → クレーム化）
3. **人間関係**（成果主義店舗のギスギス感）
4. **長時間労働**（月40時間超残業・休日出勤）
5. **クレーム対応の精神的疲弊**

### 3.3 情報収集チャネル

| 段階 | 主要チャネル |
|---|---|
| 検討初期 | 求人サイト（Indeed、求人ボックス、doda、マイナビ） |
| 選考中期 | 企業HP、公式SNSアカウント |
| 意思決定期 | 従業員個人SNS、口コミサイト |

**重要**: 20代の **81.6%** が「企業のSNSアカウントを見て応募意欲が増した」と回答（[リソースクリエイション 2025](https://rc-group.co.jp/topics/detail.php?id=172)）

### 3.4 意思決定の決め手

| 調査 | 20代の重視項目 |
|---|---|
| マイナビ2026 | ①給与・賞与 61.4% ／②リモートワーク可 43.5% |
| マイナビ転職（満足層） | 決め手は「勤務地」57.1%／「休日・残業適正」56.4% |
| マイナビ転職（不満層） | 決め手は「給与が良い」33.3% |

**示唆**: **短期意思決定は「給与」で動くが、長期定着は「勤務地・仕事内容」が効く**。給与だけで釣ると早期離職。

### 3.5 SNS利用傾向（総務省 令和6年度 情報通信メディア利用時間調査）

| SNS | 20代 | 30代 |
|---|---|---|
| YouTube | 97.2% | 97.9% |
| **X（Twitter）** | **78.0%** | 61.6% |
| TikTok | 58.7% | 39.7% |
| **Threads** | **26.5%** | 17.7% |

**Threads詳細**（2025年3月・日本MAU 1,280万人）:
- 年代別: 20代 26.5% / 10代 21.8% / 40代 20.0% / 30代 17.7%
- 男女比: ほぼ半々（男46% / 女54%）

### 3.6 世間のイメージ
- **ネガティブSEO**: 「携帯販売 きつい」「やめとけ」記事多数 → 求職者は必ず目にする
- ポジティブ: 「未経験でも稼げる」「スキル汎用性」「若手活躍」
- **求職者は「きつい/やめとけ」で検索する前提の情報設計が必要**

## 4. MinaTech への示唆（採用戦略活用）

### 4.1 刺さりやすいペルソナ

| ペルソナ | 属性 | 動機 | 訴求LP |
|---|---|---|---|
| **A. 脱ノルマの業界経験者** | 20代後半〜30代前半、キャリアショップ2〜4年経験 | 稼ぎたいがノルマ疲れ | **業務委託LP** 「1件○円・自分のペース」 |
| **B. 未経験×高日給** | 20代前半、フリーター歴あり | 日給15,000〜20,000円が魅力 | **契約社員LP** + 日給即物訴求 |
| **C. Uターン地方生活志向** | 20代後半〜30代、北海道・静岡ネイティブ | 首都圏→地元、給与は下げたくない | **急募LP** + 「転勤なし」明示 |
| **D. 業界内転職の30代** | 30代、一次代理店勤務、待遇改善狙い | 給与+働きやすさのバランス | **正社員LP** + 企業SNS強化 |

### 4.2 効果的な訴求チャネル

| チャネル | 誰に効く | 推奨運用 |
|---|---|---|
| **X** | A/B/D（20代の78%利用） | 朝7-9時 / 昼12-13時 / 夜21-23時。「働くスタッフの1日」定常発信 |
| **Threads** | A/B（20代26.5%） | 雑談トーン。「業界の本音」系が刺さる |
| **Instagram** | A/Bの女性層 | ストーリーで店舗風景・スタッフのリアル |
| **TikTok** | B（20代58.7%） | 「携帯販売員の1日」「1件成約までの流れ」動画 |
| **Indeed / 求人ボックス** | C/D（地方求人・30代Uターン） | 地域名で細分化した求人票 |
| **doda / マイナビ転職** | D（正社員志向30代） | 企業ページ充実、口コミ対策 |

### 4.3 響くコピー例
- 「日給20,000円。ノルマなし。月22日で月収44万円。」
- 「業界を辞めた人にこそ、業務委託を。1件○円、自分のペース。」
- 「北海道で働く。生活は変えずに、給料だけ変える。」
- 「未経験、1ヶ月後に月収30万を目指せる研修設計。」
- 「一次代理店から乗り換える人が増えています。理由は3つ。」（比較訴求）

### 4.4 避けるべき表現
- 「アットホームな職場」 → 20代は疑いのシグナル
- ノルマ・インセンティブの美化
- 「頑張れば稼げる」「やる気次第」等の抽象表現（数字で示す）
- 「若手活躍中」だけの空虚な訴求（具体的な数字と顔）

### 4.5 差別化のポイント
1. **ノルマ設計の透明性** — 業界最大のペインに直接答える
2. **業務委託の明示** — 契約社員・正社員・業務委託の3形態併存は業界内で強い差別化
3. **地方採用の本気度** — 北海道・静岡を「単なる地域求人」ではなく「地元完結・転勤なし」で訴求
4. **企業SNSの本気運用** — 20代の81.6%が企業SNSを見て応募意欲を左右
5. **契約形態の乗換自由度** — 年1回切替制度は業界内転職層に強く刺さる
6. **給与の3面提示** — 日給／月給／年収換算をセットで（求職者は現在給と比較したい）
